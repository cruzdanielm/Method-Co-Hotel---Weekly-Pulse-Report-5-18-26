A focused replacement for the auto-flag list. Each property's row carries five colored cells — the value visible on a tinted background. The Occ vs STLY column reads May Forecast vs same-time-prior-year. Status pill collapses the row: zero red is Healthy, one to two red is Watch, three or more red is Critical. The rightmost WoW Change column flags any property whose status moved since last week — green up-arrow for an improvement, coral down-arrow for a worsening, with a brief reason underneath.
